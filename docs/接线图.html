三、注意事项（新手必看）

  • MPU6050 只接 3.3V，千万别接到 5V，一接就冒烟。
  • 舵机接 5V（板上 VIN/5V 引脚，或 USB 口的 5V）。测试阶段两个舵机轻负载，USB 供电基本够用。
  • 如果云台转不动、舵机嗡嗡叫（堵转），或 ESP32 反复重启 → 说明电流不够，给舵机单独外接 5V 2A 电源，电源 GND 必须和 ESP32 的 GND 接到一起（共地），否则信号乱套。
  • SG90 三根线：棕=地、红=5V、橙=信号，别插反。
  • 舵机信号线（橙）只插 GPIO 数字脚，别插到电源脚。
  • 插拔舵机线前先断电（拔 USB），带电插容易烧 GPIO。
  • 机械上：两个舵机要叠放固定成 L 型——舵机2 当底座（轴朝上），舵机1 立在上面（轴朝前），才组成二轴云台。
⚠️ 最容易踩的坑：只把舵机红黑线接 ESP32 的 5V/GND，两个舵机同时大幅动作时 USB 口电流不够，板子会黑屏重启。测试没事就先用着，正式用强烈建议外接电源。

四、烧录与调试

代码已在 C:\Users\33568\Desktop\work good工作\ESP32二轴云台 准备好。烧录命令：

cd "C:\Users\33568\Desktop\work good工作\ESP32二轴云台" platformio run -t upload --upload-port COM3

看传感器实时角度（确认手的方向对不对）：

platformio device monitor -p COM3 -b 115200

如果发现左右转不跟手或方向反了，打开 src/main.cpp 顶部改 4 行配置（哪根舵机跟哪个角、要不要反向），改完重新烧录即可，不用动其它代码。
